## ⚡ Installation Instructions

### Windows
1. Download `Cordoval-OS-Setup-1.0.0.exe`.
2. Double-click the installer and follow the setup wizard.
3. Launch **Cordoval OS** from your desktop or Start Menu.

### Linux
1. Download the `.AppImage` or `.deb` package from the [Releases page](https://github.com/KierenDayStudios/Cordoval-OS-Official/releases/tag/v1.0.0).
2. For `AppImage`: Make it executable (`chmod +x Cordoval-OS-1.0.0.AppImage`) and run.
3. For `.deb`: Install via package manager (`sudo dpkg -i Cordoval-OS-1.0.0.deb`).
